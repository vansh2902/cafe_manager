# Cafe Manager ☕

A simple Python cafe billing system. Customers order items from a menu,
pick quantities, and the program prints the final bill.

## Features
- Fixed menu with prices (pizza, burger, pasta, coffee, momos)
- Quantity-based ordering with running subtotal
- Rejects items not on the menu
- Final order summary with total bill

## How to run
```bash
python cafe_manager.py
```

## Concepts used
- Dictionaries (menu and prices)
- Lists of tuples (the order)
- Loops and conditionals
- Basic arithmetic and user input
